Run it yourself

It needs Linux on x86-64, Nix with flakes, jq and python3. Run each block from a directory of its own, since each clones chat-sim.

the head 81e0b4c

git clone https://github.com/logos-messaging/chat-sim && cd chat-sim && git checkout 7a5b74c386c96b07decddc0917c96efc0c547458
pinned=$(jq -r '.nodes."logos-chat".locked.rev' flake.lock)
sed -i "s/$pinned/81e0b4cb0dca89f978b1113fc787e37c9c828aeb/g" flake.nix Cargo.toml
nix flake lock
nix develop -c cargo build --release -p harness --bin harness-run
python3 tools/sim sweep tools/sim/scenarios/grow-waku-loss-0.5-groupv3.json --from 3 --runs 1 --one-process target/release/harness-run --out tmp/grow-waku-loss-0.5-groupv3-seed-2
