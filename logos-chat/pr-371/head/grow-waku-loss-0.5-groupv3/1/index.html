Run it yourself

It needs Linux on x86-64, Nix with flakes, jq and python3. Run each block from a directory of its own, since each clones chat-sim.

pinned=$(jq -r '.nodes."logos-chat".locked.rev' flake.lock)
sed -i "s/$pinned/d1a77f443298447aa8c746bede73f829884f1473/g" flake.nix Cargo.toml
nix flake lock
nix develop -c cargo build --release -p harness --bin harness-run
python3 tools/sim sweep tools/sim/scenarios/grow-waku-loss-0.5-groupv3.json --from 1 --runs 1 --one-process target/release/harness-run --out tmp/grow-waku-loss-0.5-groupv3-seed-0
