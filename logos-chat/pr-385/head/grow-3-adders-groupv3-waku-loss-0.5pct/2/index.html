Run it yourself

It needs Linux on x86-64, Nix with flakes, jq and python3. Run each block from a directory of its own, since each clones chat-sim.

the head 041567b

git clone https://github.com/logos-messaging/chat-sim && cd chat-sim && git checkout d8db967ab1be80c821be7e4dadde2ff2b081f7b7
pinned=$(jq -r '.nodes."logos-chat".locked.rev' flake.lock)
sed -i "s/$pinned/041567bef8f424d9981218d82ee8b7f90ea979b1/g" flake.nix Cargo.toml
nix flake lock
nix develop -c cargo build --release -p harness --bin harness-run
python3 tools/sim sweep tools/sim/scenarios/grow-3-adders-groupv3-waku-loss-0.5pct.json --from 2 --runs 1 --one-process target/release/harness-run --out tmp/grow-3-adders-groupv3-waku-loss-0.5pct-seed-1
